# Juegos de la Noche

App web para encuentros musicales: **Ruleta** (acción) y **Cartas** (contar).

## Ejecutar

```bash
npm install
npm run dev
```

Abrí la URL que muestra Vite (por defecto `http://localhost:5173`).

## Editar consignas

- Ruleta: `src/data/wheelChallenges.ts`
- Cartas: `src/data/cards.ts`
